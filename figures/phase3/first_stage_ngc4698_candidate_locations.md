# Figure: NGC 4698 selector-passing source locations

**Script:** `scripts/phase3_background/plot_first_stage_host_candidates.py`
**Command:** `BUBBLETEA_EXTERNAL_DATA=~/Dropbox/work/data uv run python scripts/phase3_background/plot_first_stage_host_candidates.py`
**Data:** `$BUBBLETEA_EXTERNAL_DATA/bubbletea/gaia_host_profiles_v1/ngc_4698/scored_sources.csv`
**Date:** 2026-08-12

**Description:**
Locations of all 2,548 Gaia sources remaining after the frozen point-source contamination selector. NGC 4698 is the orange star, and the gray disk is the temporary 0--50 kpc contamination region. Circles mark preserved profile edges. Color gives Gaia G magnitude. Labels A--E identify transparent review examples chosen by location, within-ring score, or brightness; they are not a scientific candidate ranking. The selected-source surface density is broadly flat beyond 50 kpc, so this map does not show a statistically prominent host-centered concentration.
