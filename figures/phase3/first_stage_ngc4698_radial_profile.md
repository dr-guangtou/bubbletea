# Figure: First-stage NGC 4698 radial profile

**Script:** `scripts/phase3_background/plot_first_stage_host_profile.py`
**Command:** `uv run python scripts/phase3_background/plot_first_stage_host_profile.py`
**Data:** `data/results/background/first_stage_host_profile_ngc4698_v1.csv`
**Date:** 2026-08-11

**Description:**
Measured NGC 4698 surface density in all fourteen frozen physical rings. Panel A includes all Gaia sources in the frozen G-magnitude range; panel B includes only sources remaining after the frozen point-source contamination selector. Horizontal bars show ring widths, and vertical bars show exact central 68.27% Poisson counting intervals. The gray region marks the temporary 0--50 kpc contamination region, which remains excluded from first-stage inference. The small-area inner bins contain few objects; the profile beyond 50 kpc is the relevant first inspection. No final outer signal boundary is selected from this one host.
