# Figure: M60 visual audit contact sheet: 150--300 kpc

**Script:** `scripts/phase4_search/plot_m60_visual_audit_contact_sheets.py`
**Command:** `uv run python scripts/phase4_search/plot_m60_visual_audit_contact_sheets.py`
**Data:** `data/results/radial_search/m60_positive_control_visual_audit_cutouts_v1.csv; Legacy Survey DR10 Viewer JPEG cutout service`
**Date:** 2026-08-12

**Description:**
Blinded contact sheet for the 100 randomly selected M60 sources in the 150--300 kpc radial zone. Each three-color Legacy Survey DR10 cutout is 16.768 arcseconds wide and is labeled only by its permanent audit identifier. The sheet omits Gaia score, magnitude, and candidate priority to limit review bias. Images remain unreviewed when this figure is generated; the contact sheet neither assigns contamination flags nor changes the Gaia radial profile.
