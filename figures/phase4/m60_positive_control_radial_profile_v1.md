# Figure: M60 positive-control radial profile

**Script:** `scripts/phase4_search/plot_m60_positive_control_profile.py`
**Command:** `uv run python scripts/phase4_search/plot_m60_positive_control_profile.py`
**Data:** `data/results/radial_search/m60_positive_control_profile_v1.csv`
**Date:** 2026-08-12

**Description:**
Measured M60 surface density in all fourteen frozen physical rings. Panel A includes all Gaia sources in the frozen G-magnitude range; panel B includes sources retained by selector version 1. Horizontal bars show ring widths, and vertical bars show exact central 68.27% Poisson counting intervals. The gray region marks the temporary 0--50 kpc diagnostic region. Its elevated density is not used for UCD inference. No possible contaminant has been removed, and no final outer signal boundary is selected from this profile.
