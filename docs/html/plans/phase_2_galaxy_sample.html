Phase II: Target Galaxy Sample — Task Tracking

Goal: Define and prioritize the nearby galaxy sample (D < 50 Mpc) for the UCD search pipeline.

Status: In progress

Checkpoint (2026-10-12): The inherited 2,155-host table is useful for development, not a frozen final parent sample. Its May ranking and catalog are historical. Consistent half-light radii, morphology, and parent-sample completeness remain open (BT-020, BT-026, BT-027). See current status, validation stage 2, and roadmap.

II.1 Sample Compilation

  • Migrate galaxy_sample_ranked.csv from legacy project (2026-03-27)
  • Verify sample distance range ($D \le 25$ Mpc, $N=2,155$) (2026-05-11)
  • Audit distance provenance and morphological completeness (2026-05-11)
  • Manual verification of coverage check for Top 10 galaxies (100% overlap) (2026-05-11)
  • Filter by galactic latitude ($|b| > 20^\circ$ applied in legacy build) (2026-05-11)

II.2 Galaxy Properties

  • Collect total luminosities (K-band present for all 2,155 galaxies) (2026-05-11)
  • Fetch reliable morphology (Hubble type) from HyperLEDA for Top 500 galaxies (2026-05-11)
  • Fill the remaining 75% morphological gap using PGC/NGC identifiers
  • Calculate physical scales (arcsec to kpc conversion factors available via distance) (2026-05-11)
  • Verify RA/Dec completeness (100% complete) (2026-05-11)

II.3 Survey Coverage Check

  • Overlap with Legacy Survey DR10 footprint
  • Overlap with HSC-SSP footprint
  • Identify high-priority targets with deep imaging

II.4 Ranking and Prioritization

  • Define ranking metric (Luminosity, Distance, Coverage, LitBonus, FieldBonus) (2026-05-11)
  • Select Top 100 targets for Pilot Search (Phase IV) (2026-05-11)
  • Generate final target sample catalog (pilot_sample_top100.csv) (2026-05-11)
