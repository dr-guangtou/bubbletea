Gaia field-condition benchmark

Status: Bounded diagnostic completed; matching rules not yet fixed
Date: 2026-07-18
Host: NGC 4698
Gaia release reference: 2023A&A...674A...1G, DOI 10.1051/0004-6361/202243940
Artifacts: data/results/background/background_review_hosts_v1.csv, data/results/background/background_review_hosts_v1.json, data/results/background/background_field_conditions_benchmark_v1.csv and data/results/background/background_field_conditions_benchmark_v1.json

Question

Does placing comparison patches at exactly the same Galactic latitude as a target also make their Gaia coverage and total Gaia source density effectively identical?

This benchmark does not apply the UCD selector and does not count UCD candidates. The reported source counts include every Gaia DR3 catalog entry inside the circle with G magnitude between 11.262918 and 21.757988. No parallax, proper-motion, binary-star, QSO, morphology, or UCD-classifier filter is applied. It measures only field properties that can be chosen before seeing a possible galaxy excess.

Test

The test uses a circular patch of radius 0.1 degree centered on NGC 4698 and two same-size comparison patches placed east and west of it. All three patch centers have the same Galactic latitude, 71.345091 degrees. The comparison-patch separation and the group-radius multiplier are temporary test values, not approved scientific rules.

The 0.1-degree radius was selected only to make the first live archive query small and fast. It is not a proposed scientific search radius. The real galaxy measurement will use multiple concentric circular rings, retain a radial profile, and omit a calibrated central galaxy region from UCD inference.

The script measures:

  • the number and sky density of all Gaia sources in the selector's allowed G magnitude range, before applying the selector;
  • the average number of visibility periods and matched astrometric transits;
  • ecliptic latitude; and
  • M10, the median G magnitude of Gaia sources with no more than ten matched astrometric transits in the patch. Here M10 is used only as a local Gaia-depth indicator: a brighter value usually means shallower coverage.

Measured result

Patch Gaia sources Sources per square degree Mean visibility periods Mean matched transits M10 (G magnitude)
NGC 4698 target 121 3851.55 15.98 39.12 21.187
West comparison 100 3183.10 12.07 37.97 21.093
East comparison 122 3883.38 14.46 35.92 21.102

All six validation checks passed. The three patches had positive measured area, complete retrieval of the low-transit sample, no missing values in either observation-count column, and no UCD-selector output in the query contract. The complete run took 11.19 seconds on 2026-07-18.

Interpretation

Matching Galactic latitude alone did not make the three fields identical. The west comparison contained 100 Gaia sources, versus 121 and 122 in the target and east patches, and it had fewer visibility periods on average. The three M10 values were much closer, spanning 0.094 magnitude.

This is only one target and two comparison patches. It shows why Gaia coverage and total source density should be measured rather than assumed, but it cannot tell us which diagnostic is most useful or set an acceptable mismatch. Those decisions require a larger count-blind development sample and later validation against the frozen selector on spatially separate fields.

Reproduction

uv run python scripts/phase3_background/build_background_review_hosts.py
uv run python scripts/phase3_background/benchmark_gaia_field_conditions.py

Five-host Gaia field-condition review

Status: Diagnostic measurements completed; no scientific background field approved Date: 2026-07-18 Gaia release reference: 2023A&A...674A...1G, DOI 10.1051/0004-6361/202243940

Purpose

This review asks whether temporary same-Galactic-latitude comparison circles have similar Gaia coverage and total source density across five different nearby-galaxy settings. “Before selection” means that these measurements are made before applying the UCD classifier. No UCD-candidate count is used to choose or approve a field.

The five target galaxies are NGC 4698, the nearby ESO 006-G001, the group main galaxy NGC 1316, the group member M60, and the unresolved-environment case Arp 244.

Temporary geometry

In this document, a galaxy-centered test circle is a 0.1-degree-radius circle centered on the named galaxy. Earlier summaries called this the “target patch.” A comparison test circle is an equal-size circle moved away from the galaxy while remaining at the same Galactic latitude. Earlier summaries called these “diagnostic patches.” They are measured to test the method; they are not yet approved for subtracting contamination from the galaxy measurement.

The 0.1-degree radius was chosen only for a bounded archive-query test. It is not the real galaxy measurement aperture. At the catalog distances used here, this angle corresponds to a projected radius of 4.712394 kpc for ESO 006-G001 and 41.771283 kpc for NGC 4698. The real measurement must instead preserve a series of concentric circular rings in physical and host-size-normalized radius. A calibrated inner circular region will be omitted from UCD inference because galaxy substructure, compact star-forming regions, and H II regions can dominate it.

For the four galaxies with accepted Kourkchi-Tully catalog associations, two comparison test circles were placed east and west at exactly the galaxy's Galactic latitude. Their temporary separation uses twice the catalog's estimated collapsed-group radius, followed by a 1.2 center-separation multiplier. These are test values, not approved halo boundaries.

For group cases, each comparison test circle was also checked against a circle centered on the catalog's group main galaxy. All four group test circles clear that temporary boundary, but this does not make them valid scientific backgrounds. Arp 244 has no accepted environment association, so only its galaxy-centered circle was measured. We did not create off-galaxy comparison coordinates from an unverified group center or group size. That is what the earlier phrase “no invented comparison” meant; it did not mean that any observed data were fabricated.

Quantities measured

  • Total Gaia source count and density: every Gaia DR3 catalog entry inside the circle whose G magnitude lies between 11.262918 and 21.757988. No parallax, proper-motion, binary-star, QSO, morphology, or UCD-classifier filter is applied. These counts are therefore expected to be dominated by ordinary Milky Way stars.
  • Visibility periods: separated groups of Gaia observations contributing to a source. The table reports the average within each patch.
  • Matched astrometric transits: individual Gaia passages associated with a source's astrometric processing. The table reports the patch average.
  • M10: the median G magnitude of Gaia entries with no more than ten matched astrometric transits and a reported G magnitude. Unlike the total-count column, this depth calculation is not restricted to the classifier's G-magnitude range. It is a local Gaia-depth indicator; a brighter value generally indicates shallower coverage.

Interpretation

The two one-galaxy catalog cases have comparatively small M10 ranges across their three patches: 0.094 magnitude for NGC 4698 and 0.105 magnitude for ESO 006-G001. The group cases have larger ranges: 0.503 magnitude for NGC 1316 and 0.498 magnitude for M60. The average observation counts also vary substantially within some sets. This confirms that exact Galactic-latitude matching does not guarantee similar Gaia coverage.

Total Gaia density needs more careful treatment. M60's target patch contains 289 Gaia sources, while its test patches contain 59 and 130. The target patch may contain real sources associated with M60 or the Virgo environment, not merely a different level of Gaia crowding or completeness. Therefore total Gaia density is a useful diagnostic but cannot be required to match the target rigidly: doing so could reject genuine host-associated populations before the UCD selector is even applied.

The next calibration should learn how field properties predict selected-source density from comparison fields that are not centered on target galaxies. It should then test that relationship on spatially separate comparison fields. Target overdensities must not be used to choose the matching tolerances.

Off-target development and validation fields

Status: Bounded diagnostic split frozen Date: 2026-07-18 Issues: BT-005, BT-009

Plain-language definitions

An off-target field here is one of the existing 0.1-degree test circles placed away from a review galaxy. These circles were created to test background methods; they are not the real galaxy measurement rings.

  • Development fields may be used to choose or adjust the background method.
  • Validation fields are held back until those choices are fixed. They then test whether the method works in different sky regions.
  • Excluded fields are the five galaxy-centered test circles. They are not part of this off-target split.

“Held back” is a procedural rule: selector results from validation fields must not be used to choose cuts, matching tolerances, or model settings.

Frozen assignment

The split identifier is split_04329736d47c538b7aa0.

Both off-target circles generated from one host remain in the same partition. This prevents closely related east/west measurements from appearing on opposite sides of the method test. Each partition contains one isolated case, one grouped case, one positive Galactic latitude, and one negative Galactic latitude.

The smallest measured center-to-center separation between a development circle and a validation circle is 11.949376 degrees. The test-circle diameter is 0.2 degree, so no development circle overlaps a validation circle.

What was not used

The assignment script reads only the previously frozen field positions and their host, environment, and sky coordinates. It does not read the field-condition table, Gaia source counts, source densities, or frozen-selector results.

Pre-selector field-condition measurements already exist for these positions and have been discussed previously. They were not inputs to this assignment. No selected-source count has been calculated or inspected for this split.

Important limitation

These eight circles form a small first experiment, not a final survey-wide validation sample. All still have eligible_for_scientific_background = false. The split allows the canonical selector experiment to test procedure and leakage control; it does not approve any circle as the background for a real galaxy or calibrate a final Galactic-latitude limit.

What was done

The four frozen development circles were queried for all 19 Gaia columns required by point_source_logistic_model_v1. The selector was then applied locally, using its frozen probability threshold of 0.8277833628791744.

Frozen development summary rules

Status: Summary procedure frozen before validation Date: 2026-07-18 Issues: BT-005, BT-009

What is frozen

The development results will be summarized at three levels:

  1. Keep each of the four fields as a separate measurement.
  2. Combine east and west fields only when they come from the same host system.
  3. Show one all-development total for description only, not as a universal background density.

The frozen selector threshold remains 0.8277833628791744. It will not be changed after seeing these counts. No development field is promoted to an approved scientific background.

Small-count ranges in plain language

When only a few sources are counted, repeating an equivalent measurement can produce a different count by chance. A Poisson model is the standard simple model for that random counting variation when events are independent and have one average rate over a fixed area.

For every field and combined row, the table records 68% and 95% exact central Poisson ranges. These give ranges of average counts compatible with the observed small count under that simple model. The corresponding density ranges divide the count ranges by the exact usable area.

The percentage describes repeated use of the procedure: under the Poisson model, ranges constructed this way include the true average rate at least that percentage of the time over many equivalent experiments. It is not the probability that one particular displayed range contains the true value.

These ranges do not include real differences among sky fields, correlated sources, changes in Gaia observing conditions, or uncertainty in the selector. They are therefore counting-only ranges, not the final background uncertainty.

Held-back off-target validation result

Status: One-time held-back check complete; no field approved as a scientific background Date: 2026-07-19 Issues: BT-005, BT-009

What was tested

The four off-target circles kept out of development were opened after the selector and summary rules were fixed. The run used the same 19 Gaia columns, G-magnitude range, selector version, probability threshold, 0.1-degree circle, usable-area definition, east/west host pairing, and counting-only ranges used for development. No setting was changed after the validation counts became visible.

Here, validation means a one-time check on circles whose selector probabilities, decisions, and passing-source counts were not used to choose the procedure. Earlier measurements of total Gaia source density and observing conditions at these positions were allowed and remain separate.

A source that passes the selector is a retained search candidate, not a confirmed UCD. These circles are diagnostic measurements and are not approved backgrounds for a host-galaxy measurement.

Comparison with development

The combined validation density is 1.181818 times the combined development density of 350.140964 per square degree. It falls outside the development 68% counting-only range but inside the development 95% range. This is a description, not a rule that the result must pass.

Individual development fields span 190.985980–572.957941 per square degree, while validation fields span 95.492990–604.788937. Development host pairs span 286.478970–413.802957, while validation host pairs span 270.563472–557.042442. Both pairs of ranges overlap.

The result supports the limited claim that the fixed procedure can be executed on untouched fields without an obvious incompatible total density. It also shows large field-to-field variation. Four validation circles from two host systems are therefore too few and too small to define a survey-wide background model, matching tolerance, or Galactic-latitude limit.
