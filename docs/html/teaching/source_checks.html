Foreground comparison query

SELECT TOP 3 source_id, ra, dec, phot_g_mean_mag, bp_rp,
       parallax, parallax_error, pmra, pmra_error, pmdec, pmdec_error,
       pmra_pmdec_corr, ruwe, astrometric_excess_noise,
       astrometric_excess_noise_sig, phot_bp_rp_excess_factor
FROM gaiadr3.gaia_source
WHERE 1 = CONTAINS(POINT('ICRS', ra, dec),
                  CIRCLE('ICRS', 190.54602278774948, 11.644788807179935, 0.15))
  AND phot_g_mean_mag BETWEEN 17 AND 19
  AND bp_rp BETWEEN 1.0 AND 2.0
  AND parallax_over_error > 10
  AND ruwe < 1.2
  AND SQRT(pmra * pmra + pmdec * pmdec) > 10
ORDER BY phot_g_mean_mag ASC

Optional significance calculation

For parallax use abs(parallax) / parallax_error. For a two-component proper motion, account for the correlation rho = pmra_pmdec_corr:

u = pmra / pmra_error
v = pmdec / pmdec_error
combined_motion_significance = sqrt((u*u + v*v - 2*rho*u*v) / (1-rho*rho))

This is distance from zero motion in units defined by the covariance matrix; it is not directly a one-dimensional Gaussian tail probability. Calculated values: M60-UCD1 parallax 0.200, combined motion 1.337; M59-UCD3 parallax 0.887, combined motion 0.742. These calculations use the quoted random-error covariance and do not correct Gaia systematics or modeling failures.

Legacy Survey checks

The official DR11 description documents both the standard layer and a grz alternative. Actual requests for the two worked examples gave:

ls-dr11-grz, M60-UCD1 HTTP 200, 128×128 JPEG Every channel of every pixel equals 32 Blank tile, not usable imaging
ls-dr11-grz, M59-UCD3 HTTP 200, 128×128 JPEG Every channel of every pixel equals 32 Blank tile, not usable imaging
ls-dr11, M60-UCD1 HTTP 200, 128×128 JPEG 4,153 distinct RGB colors; visually checked Compact central source, host-light gradient, nearby streaks

Color counts detect a blank response; they do not measure scientific image quality.

Request pattern, substituting the exact coordinates in the shortlist:

https://www.legacysurvey.org/viewer/jpeg-cutout?ra=RA&dec=DEC&layer=ls-dr11&pixscale=0.262&size=128

The square covers 33.536 arcseconds per side. Standard DR11 JPEG colors need not use the same bands as previous grz displays, so label the layer and do not infer photometric colors from the displayed RGB values. Preserve the blank responses as failed content checks rather than silently substituting a different release.

  • m60_ucd1_dr11_grz.jpg and m59_ucd3_dr11_grz.jpg: blank responses.
  • m60_ucd1_dr11_default.jpg and m59_ucd3_dr11_default.jpg: inspected images.

Host-center tests used fits-cutout, layer=ls-dr11, bands=grz, size=32, pixscale=0.262, at the exact host coordinates in the shortlist. NGC 2974 and NGC 4753 returned three 32×32 planes, each with 1,024 finite and nonzero pixels. Their wider JPEG tests (size=256, pixscale=4) had 6,392 and 7,244 distinct RGB colors, respectively. These responses were inspected numerically in memory, not saved as a host-coverage data product and not visually adjudicated. NGC 1395's first FITS request returned HTTP 429, a rate limit, not evidence of missing survey coverage. A later serial retry returned HTTP 200 and three 32×32 planes, each with 1,024 finite and nonzero pixels. Do not repeat concurrent host requests or launch a bulk download yet; use serial requests and backoff.

Full-area coverage, per-band weights, image defects, host-background effects, and actual candidate cutouts still need checking. Legacy image availability never changes the Gaia radial-area denominator.

Its approved canonical classification is confirmed, while the original source's reported label is candidate. Its canonical position is 190.8998699, 11.5346389; the source row has no Gaia identifier. The live Gaia match is an independently recorded teaching check, not a newly accepted database association.

The two M60 review seeds link to datasets from Liu et al. 2015 (2015ApJ...812...34L, original reference/liu2015/table6.dat) and Fahrion et al. 2019 (2019A&A...625A..50F, inherited comparative compilation at data/literature/catalogs/by_source/2019A&A...625A..50V.csv). Use the original publication/table context and the approved classification, not the inherited source labels alone. The subsequent portable packet below preserves these distinctions; candidate status is not confirmation.
