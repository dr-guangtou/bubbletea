伪装成恒星的星系

项目简介 | BubbleTea 第一部分 | 实测天文学

为什么要寻找“看起来像恒星”的星系？

超致密矮星系（ultra-compact dwarf galaxy，简称 UCD）是一类紧凑的恒星系统， 处于大质量星团与小星系之间的模糊边界。它的光来自许多恒星，但距离足够远时， 在图像中可能看起来只是一颗恒星。有些 UCD 可能是较大星系在引力相互作用中失去 外围恒星后留下的中心；另一些则可能原本就是质量很大的星团。它们的起源仍是研究 问题，并不能仅凭“星系”这个名称确定。

这些小天体可能保存着更大星系的历史。例如，对 M60-UCD1 的详细观测发现了一个 大质量黑洞，支持它源自较大星系的解释。这项结论所需的证据远不止一张照片。 Seth 等（2014）

目前的 UCD 样本仍不完整，过去的搜寻主要集中在星系团和星系群中。研究较少的 大质量星系周围是否藏着尚未发现的 UCD？盘星系周围或较稀疏环境中的 UCD 有多常见？ 这些问题是本学期项目的动机，并不意味着每个星系周围都有可探测到的 UCD，也不保证 我们一定能获得新发现。HTML 活动文件中提供了实例和延伸阅读。

用两种互补的方式观察天空

Gaia 通过反复扫描天空记录天体的位置、亮度、颜色、视差和自行。它探测的是 集中的光，而不是先确认目标属于恒星再记录数据。因此，紧凑的星系和类星体也可能 出现在 Gaia 星表中。探测器像元的大小、分开两个相邻天体的能力，以及测量位置的 精度，是不同的概念。ESA：Gaia

Legacy Survey 图像则帮助我们观察天体的外观及其周围环境。大气和仪器造成的 模糊会让小天体看起来像一个点；同一个天体在更远的距离上也显得更小。彩色图像是 一种显示方式，不能代替实际测量的流量和颜色。本活动结合保存的 Gaia DR3 记录 与 Legacy Survey DR11 图像。Legacy Survey DR11

如何开始

把 ucd_investigation.html 保存到电脑上，用桌面浏览器直接打开，不要在邮件或 课程平台的预览窗口中操作。所需的数据、图像和交互工具都包含在这一个文件里。 完成核心任务不需要编程、安装软件、注册账号、架设服务器或连接网络；只有可选的 在线探索需要联网。

先阅读背景、示意图和测量量的定义，再比较已标明类别的实例。核心阅读按约 30 分钟 设计，实际探索与完成任务需要额外时间。这是学期项目的第一部分；搜寻新的候选体 将在后续部分开展，不是本次作业的要求。

你需要完成什么？

目标是把观测与物理解释联系起来，用真实数据检验筛选规则，并说明规则的作用和 局限。请根据实例发展自己的判断，而不是寻找一个完美的捷径。HTML 文件中包含 测量量的定义，以及可展开查看的工具操作说明。

任务一 | 为 30 个天体分类

逐个查看天体的近景图、较大视场图、Gaia 测量值和相关链接，为每个天体选择 UCD、恒星、类星体（QSO）或不确定。只有分类选择是必填项；置信程度、所用证据、 简短说明和外部参考资料均为可选，但它们有助于记录你的判断过程。你可以返回修改 选择；页面不会公布正确答案。

把测量值和不确定度一起阅读。“Not supplied”表示数据缺失，不是零。区分观测直接 显示的事实与你的推断。查询在线星表时，请核对是否为同一个天体。页面折叠的指南 介绍了 Gaia Archive、Legacy Survey 和 Aladin 的使用方法；在线核查是可选探索， 不是额外的必交内容。

任务二 | 设计并改进筛选规则

在交互图中探索 21,118 个真实星表天体。这个教学样本特意以恒星为主。启用你 选择的测量范围、调整上下限，并决定如何处理缺失值。一个天体必须满足所有已启用 的条件才会被选中。点击 Evaluate selection，才能记录一次尝试并查看选中天体 与评价指标；只移动滑块并不会产生新的评价记录。

  • 完整度（completeness）：参考 UCD 中，被规则选中的比例。
  • 纯度（purity）：在具有可靠参考类别的已选天体中，UCD 所占的比例；其余为恒星或类星体。
  • F1：纯度与完整度的调和平均值，是同时考虑两者的综合指标。请尝试提高 F1， 同时查看选中数量、纯度和完整度。

尚未确认的候选体会单独计数，不参与上述指标。这个样本是为教学组织的；在同一 样本上反复调整规则后得到的分数，并不能代表对新天区的实际表现。高分也不能证明 某一个候选体就是 UCD。本任务不要求实现完美分类。

尝试不同规则并比较记录，最后选定一次已评价的尝试作为最终方案，在页面中回答：

  • 你为什么认为这个方案有效？（Why do you think this works?）
  • 你认为这个筛选方案还可以怎样改进？（How do you think this selection can be improved?）

任务三 | 判断物理关联

在页面中回答下面的问题。你的回答将作为第二部分讨论的起点：

你在天空中一个大质量星系附近找到一个可能的 UCD。你会如何研究它是否与这个 星系存在真实的物理关联？

需要提交什么？

提交从 HTML 活动中导出的一个 JSON 答案文件。其中包含你的学号、任务一的 30 个分类记录、任务二的尝试历史与最终方案及两项解释、任务三的回答，以及简短的 大语言模型使用说明。第一部分不要求另交报告、截图集、代码或新发现声明。 可选的 TXT 导出便于阅读，但不能代替 JSON 作业文件。

保存、检查与提交

  1. 在 Keep a record 区域的 Student ID 中填写你的学号，并完成大语言模型 使用声明。如果使用过，请简要说明它提供了什么帮助，以及你核查了哪些内容。
  2. 确认 30 个天体都有分类；任务二已选择一个评价过的最终方案并填写两项解释； 任务三已有回答。“不确定”是有效分类，不等于未作答。
  3. 点击 Download answers · JSON。找到下载的文件，将其重命名为 [NAME]_[STUDENT_ID].json：用你的姓名替换 NAME，用你的学号替换 STUDENT_ID，去掉方括号，保留 .json 扩展名。
  4. 将这个 JSON 文件上传到网络学堂（Tsinghua Online Classroom）中老师指定 的作业位置，并确认上传成功。截止时间以课程通知为准。
  5. 在本地保留最终 JSON 文件，以及完成作业时使用的那一份 HTML 文件。

网页表单只填写学号；姓名写在提交文件的文件名中。如果系统隐藏了文件扩展名， 请避免把 .json 重复添加两次。下载文件不等于已经上传到网络学堂。

如何避免丢失进度

尽早下载 JSON，并在重要修改后再次下载，即使任务尚未完成也可以导出。浏览器中 的草稿保存只是便利功能，不能当作可靠备份；移动 HTML 或更换浏览器后，原来的 草稿可能无法读取。你下载到电脑上的 HTML 文件本身不会自动写入答案。

下次继续时，打开同一份 HTML，在 Resume from a saved JSON file 处选择你保存 的 JSON。导入会替换当前答案，所以应先导出当前需要保留的工作。重命名 JSON 不会改变其内容，请不要手动编辑文件内部的数据。继续修改后要重新下载 JSON， 最后提交更新后的版本，而不是较早的草稿。

负责任地使用大语言模型

本项目允许并鼓励合理使用大语言模型。它可以帮助解释概念、组织思路或建议核查 方法，但语气自信的回答并不是观测证据。请用提供的测量值和可靠资料核对事实。 你提交的判断与解释应反映自己实际检查过的内容。只需填写简短的使用说明， 不需要提交私人聊天记录。

本次目标：留下可复查的判断记录、一个经过检验的筛选方案，以及对天体物理 关联问题的思考。这些将成为项目下一阶段的基础。
