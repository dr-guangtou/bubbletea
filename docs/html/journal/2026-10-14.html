Progress

  • Prepared 30 classification objects and a separate 21,118-object selection catalog: 20,000 stars, 121 UCD references, 391 QSOs, and 606 unconfirmed candidates. Embedded 74 reviewed Legacy Survey DR11 cutouts; retained provenance and exact Gaia identifiers without changing research catalogs or selectors.

Kept uncertain candidates outside the scores and enabled responsible LLM use with brief disclosure.
  • Improved the Task 1 layout so images remain beside desktop classification controls. Added compatible JSON export/import, an independent instructor checker, Student ID wording, and [NAME]_[STUDENT_ID].json submission instructions for Tsinghua Online Classroom.
  • Fixed five review findings: import-state rollback and identifier typing, malformed numeric input, missing excess-noise table values, stale hover text, and floating-point slider endpoints. The offline suite passed 43,740 assertions, including 26 focused regressions; the frozen packet and answer schema remained unchanged.
  • Delivered equivalent English/Chinese Project Introduction Markdown and three-page PDFs, checked all six rendered pages and embedded fonts, and retained the previous six-object HTML/PDF separately as version 1. The finalized HTML measured 9,354,951 bytes; fourfold-throttled startup was 0.795206 seconds and median evaluation plus redraw was 64.5 ms.
  • Updated the specification, completed BT-033, linked the classroom artifacts, and rebuilt the documentation portal. Before this journal addition, 316 documentation checks and scoped Ruff/pre-commit checks passed. Implementation details and reproduction commands are in docs/development/teaching_materials.md.

Next Steps

  • Complete the authorized Git closeout after recording the daily snapshot and validating the added journal page.
  • The instructor will post the finalized HTML and preferred introduction PDFs, announce the deadline, and collect named JSON submissions.
  • When development resumes, scope Part II separately, beginning with students' answers about physical association with a host galaxy. New-host literature, imaging coverage, and sensitivity checks are prerequisites to a discovery exercise.

Lessons Learned

  • Test import failures after validation and before persistence; ordinary malformed-file rejection does not demonstrate rollback safety.
  • Distinguish incomplete numeric input from an intentionally empty bound, and exercise exact slider endpoints through their event handlers.
  • Validate the interaction students actually perform, including image visibility during evidence entry and navigation, not only page overflow.
  • Retain uncertainty and provenance in classroom data; optimize F1 for a selected list rather than substitute a ranking metric for range cuts.
  • Check Unicode font resources, extracted text, and every rendered page when producing bilingual PDFs. Scope auto-fixing hooks to changed files to avoid unrelated legacy edits.
