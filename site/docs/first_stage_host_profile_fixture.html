First-stage host profile fixture

Date: 2026-08-11

Script: scripts/phase3_background/freeze_first_stage_host_profiles.py

Command: uv run python scripts/phase3_background/freeze_first_stage_host_profiles.py

Outputs:

  • data/results/background/first_stage_host_profile_fixture_v1.csv
  • data/results/background/first_stage_host_profile_fixture_v1.json

Purpose

This fixture defines the physical rings to retrieve before any large-radius Gaia source count is inspected. It uses the five review galaxies that were already selected from host identity, distance, and environment information alone.

Every host retains the same 14 rings with edges at 0, 5, 10, 15, 20, 25, 30, 40, 50, 75, 100, 150, 200, 300, and 600 kpc. The source-level output must also retain continuous physical radius so these rings can be recombined without another Gaia query.

Temporary central treatment

The inner 0--50 kpc is labeled as a conservative contamination region for the first stage. Its eight component rings remain in the output, but they are withheld from UCD inference. Candidate boundaries at 20, 25, 30, 40, and 50 kpc may later be compared using contamination behavior; they cannot be selected because one gives a larger apparent UCD excess.

This 50 kpc choice is deliberately conservative and temporary. It is not a claim that every galaxy has a 50 kpc visible body.

Outer profile

Every requested profile reaches 600 kpc. No final outer signal boundary is selected yet. The measured profile will be inspected first, and failed or incomplete outer coverage will remain missing area rather than silently shortening the profile.

Galaxy-size-normalized view

The current host table contains no verified R50, the radius enclosing half of a galaxy's light. Physical profiles therefore remain available, while the R50- normalized view is explicitly unavailable. Once a provenance-bearing R50 is added, both views must be reported.

First live benchmark

NGC 4698 is the first archive benchmark because it has the smallest 600 kpc angular radius among the fixed review galaxies whose isolated-environment association is resolved. This is a geometry-only choice and uses no Gaia source count.

All 16 fixture checks pass with zero archive queries.

The count-only 600 kpc NGC 4698 benchmark measured 23,811 Gaia sources in the frozen G-magnitude range over 6.478776 square degrees. The archive returned the single aggregate count in 2.004 seconds. No source rows were downloaded, and the point-source contamination selector was not applied. All nine benchmark checks pass.

The next step is the explicitly bounded, resumable NGC 4698 source retrieval. Its output will report both the density of all Gaia sources in the frozen magnitude range and the density that remains after the point-source contamination selector in every preserved physical ring.

First measured profile

The complete source retrieval used six non-overlapping sky strips, each containing no more than the previously validated 5,000-row limit. It retrieved all 23,811 unique sources and retained their continuous angular and projected physical radius outside the repository under BUBBLETEA_EXTERNAL_DATA. The frozen point-source contamination selector retained 2,548 sources. All fourteen run checks pass.

Outside the temporary 50 kpc central exclusion, the all-source density ranges from 3,599.136759 to 4,087.777954 per square degree and the selector-passing density ranges from 317.377181 to 426.550743 per square degree. The six outer rings contain 23,650 all-source objects and 2,530 selector-passing objects over 6.433764 square degrees. The remaining ring-to-ring variation is consistent with a broadly flat first profile, but one host is not enough to select a final outer signal boundary.

The inner bins have very small areas and few objects. For example, the apparently high selector-passing density inside 5 kpc is based on one object. The temporary 0--50 kpc exclusion therefore remains unchanged rather than being tightened from this profile.

The profile is shown in figures/phase3/first_stage_ngc4698_radial_profile.png. Vertical error bars are exact central 68.27% intervals from counting uncertainty; horizontal bars show the full physical width of each ring.

The locations of all passing sources and their distributions in the nine frozen selector features are documented in docs/first_stage_ngc4698_candidate_diagnostics.md. That diagnostic finds no strong Gaia-only standout and changes no selector or radial boundary.
