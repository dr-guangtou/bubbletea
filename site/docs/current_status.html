The question we are trying to answer

Can Gaia measurements identify a reproducible excess of ultra-compact dwarf galaxies (UCDs) around nearby galaxies? A UCD is a compact stellar system whose size or luminosity can place it beyond ordinary globular clusters. A source passing our Gaia selection is not automatically a UCD.

Population measurements come first; individual candidate lists are secondary. External images help interpret sources but must not silently change membership or area in the frozen Gaia-only measurements.

Where work stopped

On 2026-10-12 the local review database contained zero saved review revisions. The checked-in August 17 exports also record zero reviewed objects. The workbench is implemented, but no clean, visually reviewed positive reference has yet been produced from it. The stored API validation reports 15 passing checks; this restart audit did not rerun browser tests.

Both confirmed objects and candidates use include, exclude, or hold review decisions. For a candidate, include means retain in the follow-up pool, never promote to confirmed. Original data and classifications remain unchanged.

Next research steps

  1. Verify the local workbench and review a small, varied pilot before the full list.
  2. Review reference images and source identifications, preserving uncertainty and correction proposals rather than editing the canonical catalog.
  3. Export a clean confirmed-UCD design reference and a separate candidate pool.
  4. Inspect the representative M60 sample to measure real-field contamination; do not substitute a promising-candidate shortlist for that sample.
  5. Test selection improvements against the frozen baseline before scaling up.

The workbench launch command is in its README.

What prevents final scientific claims

  • Selection sensitivity: Completeness and contamination must be measured over magnitude, distance, size, and Gaia measurement availability. A selection score is not a calibrated probability that a source is a UCD.
  • Host properties: The inherited 2,155-galaxy table is useful, but the final parent sample, consistent morphology, and half-light radii remain unfinished. A half-light radius is the radius enclosing half a galaxy's measured light.
  • Radial boundaries: The initial 0--50 kpc exclusion and 600 kpc reach are conservative working geometry, not final scientific limits. Preserve all rings.
  • Background and uncertainty: Random-field measurements are available, but valid host-specific comparisons, group/cluster treatment, and calibrated overdensity significance still require work.

See the validation stages for acceptance requirements; completed software is not equivalent to completed science.

Documentation and teaching pivot

The current task is documentation maintenance and a static HTML reading portal. It does not change any scientific selector, catalog, image classification, or radial measurement. An observational-astronomy teaching project will follow as a separate brief. Audience, lesson scope, exercises, and student data access have not yet been specified; research plans must not be presented as established results.

Snapshot limitations

This page records the repository and local data inspected on the review date. Review counts, branch names, and remote state can change afterward. The issue register tracks work; the journal preserves dated evidence. Update this page when the next substantial checkpoint is reached.
