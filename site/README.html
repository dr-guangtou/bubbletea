BubbleTea

Searching for Ultra-Compact Dwarf (UCD) galaxies and other compact stellar systems in the nearby universe using Gaia DR3 astrometry and imaging survey photometry.

Restart checkpoint: 2026-10-12. The visual-review tool is implemented; the local 724-object review database has no saved reviews. Start with current status, the documentation guide, or the generated HTML portal.

Scientific Goal

Perform a systematic Gaia-only search for UCD candidates around nearby galaxies. Gaia evidence of non-point-like structure is combined with host-centered excess statistics; external imaging and spectroscopy are value-added characterization, not inputs to the primary population selection.

Method

  1. Gaia-only source selection: Use the frozen version-1 logistic selector as a reproducible baseline. Its score is not a probability of physical UCD identity; final sensitivity and contamination calibration remain unfinished.
  2. Host-centered statistics: Measure positive, null, and negative excesses against validated local or control-field backgrounds.
  3. Value-added characterization: Use Legacy Survey and other external data to describe covered subsets without changing Gaia statistical membership.

Project Phases

Phase Description Status

Ib Ancillary data collection (DESI, multi-wavelength) Legacy Survey reference prepared; wider enrichment pending
II Target galaxy sample definition and prioritization (D < 50 Mpc) Inherited catalog audited; final sample and properties open
III Background density characterization (galactic latitude dependence) 500 fields complete; host-specific calibration open
IV Pilot search around confirmed UCD hosts + high-priority targets NGC 4698/M60 profiles measured; contamination review pending
V Cross-match candidates with imaging and spectroscopic data Planned
VI Statistical analysis, discussion, and future perspectives Planned

See the roadmap, validation stages, and issue register. Early exploratory pilot claims are not final results.

Quick Start

# Install dependencies
uv sync

# Set up pre-commit hooks
uv run pre-commit install

# Set external data path (large catalogs not in repo)
export BUBBLETEA_EXTERNAL_DATA=/path/to/your/data

# Run a script
PYTHONPATH=. uv run python scripts/phase1_literature/analyze_gaia_properties.py

To build the documentation portal, run uv run python scripts/documentation/build_documentation.py, then open index.html. The workbench README explains how to launch the separate source-review application; the static portal does not save reviews.

Data Provenance

All data in this project is traceable to its original source. Each entry in the literature database records the ADS bibcode, DOI, and VizieR catalog ID. The reference/ directory contains a folder per paper with the PDF and original data files. See reference/summary.md for the literature tracking table.

Key References

  • Voggel et al. (2020), ApJ 899, 140 — Gaia-based UCD selection methodology
  • Wang et al. (2023), ApJ 954, 206 — Gaia GC search around M31
  • Saifollahi et al. (2021), MNRAS 504, 3580 — Fornax UCD sample

Validated Reference State

  • 5,049 literature records from 14 record-contributing publications are preserved in the non-destructive v2 database, which registers 30 publication provenance packages in total.
  • 4,359 canonical objects are classified as 740 confirmed, 1,515 candidate, 2,082 rejected, and 22 uncertain under confirmation_rules_v1.
  • 963 canonical Gaia associations represent 962 unique Gaia DR3 sources.
  • 3,723 Legacy Survey DR10 matches are retained as value-added enrichment; complete audits include all 4,359 canonical targets.
  • Historical pilot thresholds, match rates, and host contrasts remain exploratory. The shared selector and direct background measurements now exist, but final host-specific inference and selection sensitivity are still unfinished.

The generated counts and validation state are recorded in data/literature/validation/project_status_counts.json.
